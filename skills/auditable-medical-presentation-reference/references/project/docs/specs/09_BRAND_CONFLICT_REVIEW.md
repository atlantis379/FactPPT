# 品牌名冲突复查：FactPPT v0.1

> 目的：注册 factppt.com 前，检查 "FactPPT" 是否与已有品牌/商标/产品冲突，评估风险等级并给出结论。
> 方法：web 搜索（中文/韩文/英文）+ RDAP 域名检查 + 商标库核查 + 竞品动态。复查日期：2026-09。
> 结论先行：**"FactPPT" 这个确切品牌名未见直接占用；但存在一个高度相关的已注册商标「FACTIFY」和一个名称相近的竞品「FactChat」，构成了"商标距离 + 市场混淆"的双重风险，需要决策。**

## 2. 最关键的发现：UK00004059165「FACTIFY」商标（高度相关，需重点评估）

来源：[英国知识产权局官方商标库](https://trademarks.ipo.gov.uk/ipo-tmcase/page/Results/1/UK00004059165)（已抓取原文，正文见下）

- **商标名**：FACTIFY
- **注册人**：Factify Technologies Inc.（美国特拉华州 / 斯坦福）
- **注册日期**：2024-06-03 申请、2024-09-27 生效，2034-06-03 续展
- **类别 9**：可下载软件，用于"**证明书面和电子通信中主张/断言为事实**"
- **类别 42**：提供网站技术，允许用户"**证明通信中主张为事实**"

**为什么危险**：
1. **类目描述几乎就是你的定位**——"证明数字/内容为事实"+"可验证来源"，和 FactPPT 的"忠实转换、拒绝幻觉、来源可查"在语义上高度重叠；
2. **语义相近**：FACTIFY（使成为事实） vs FactPPT（事实 + PPT）——在"事实/验证"含义上双关，商标近似风险高；
3. **已注册且活跃**：2024 年申请，已在美国/英国布局（[USPTO 组合](https://www.trademarkelite.com/trademark/trademark-owner/FACTIFY%20TECHNOLOGIES%20INC.)、[专利组合](https://www.patentguru.com/cn/assignee/factify-technologies-inc)）。

**但差异点（可辩护空间）**：
- 名称**不完全相同**：FACTIFY ≠ FactPPT；
- 类目 9/42 的措辞是"证明文字主张为事实"（更像内容认证/取证工具），**未明确覆盖"演示文稿/PPT/幻灯片生成"**这个具体商品；
- 你的产品落在"软件即演示文稿生成 + 事实追溯"，与纯"主张认证"定位有区隔。

**风险等级：中高**（若是同国家市场）。结论不是"不能用"，而是——**若未来进入海外市场，FACTIFY 可能与 FactPPT 构成混淆性近似，尤其在你把"Fact"含义作为卖点时。**

## 3. 名称相近的市场竞品（混淆风险）

### 3.1 MindLogic「FactChat」——韩国，教育生成式 AI 平台，已上线 PPT 功能（最直接的名称+场景双重接近）

来源：[MindLogic 官方博客（已抓取原文）](https://blog.mindlogic.ai/post/29)、[韩联社](https://www.yna.co.kr/view/AKR20250529137500017)、[Platum](https://platum.kr/archives/283672)

- **名称**：FactChat（Fact 前缀 + AI 对话产品）
- **业务**：生成式 AI 平台，主打"事实核查"功能；**2026-03 已上线"演示文稿标签页"**——输入主题 → AI 做网络调研 → 生成幻灯片（PPTX/PDF）→ 支持上传 PDF/DOCX/HWP/Excel → 自动做图表
- **规模**：50 万付费用户、韩国 19 所大学 + 219 所中小学采用、营收同比增 12 倍（55 亿韩元）
- **与 FactPPT 的区隔**：FactChat 是"对话+调研+生成"的全能平台，**不主打"忠实原始材料/来源级可追溯"**——你的差异化仍成立；但**名称都以 Fact 开头 + 都做 AI PPT + 都面向教育/专业场景**，在中文/韩文市场的搜索与心智上可能互相干扰。

### 3.2 FactSet「AI Pitch Creator」——全球金融数据巨头

来源：[FactSet 官方新闻稿](https://www.factset.com/marketplace/catalog/product/pitch-creator)

- 金融信息巨头 FactSet（纳斯达克：FDS）推出 AI 生成投行 pitchbook 工具；
- 名称不同（FactSet ≠ FactPPT），**不构成商标冲突**，但同处"AI 生成演示内容"赛道，且"Fact"含义相关，营销话术上需区分。

### 3.3 Factify 同名其他业务（以色列 PDF 替代创业公司）

- 同名 "Factify" 的另一家以色列公司做"AI 文档替代 PDF"（融资 7300 万美元）——与 FactPPT 无直接冲突，但进一步说明 **"Fact*" 前缀在 AI/文档/验证赛道已被多家使用**。

## 5. 结论与建议

### 5.1 结论：FactPPT 可以用，但有"必须提前处理"的风险

1. **直接使用 FactPPT 当前没有障碍**（无同名商标/域名/产品阻挡），注册 factppt.com 没毛病；
2. **但要把"FACTIFY 商标 + Fact 前缀拥挤"当作已知风险计入决策**，尤其是你已把"Fact/事实"当作核心卖点——这会放大与 FACTIFY 的语义近似。

### 5.2 建议（按力度排序）

**方案 A（推荐，低成本规避）**：**保留 FactPPT，但强化差异化定位表述**——对外永远用 "FactPPT：把原始材料变成可验证的 PPT" 这类完整句，让"PPT/演示"成为区别点，弱化与 FACTIFY"证明主张"的语义重叠；商标检索上若出海，在重点市场（US/EU/UK）做一次正式冲突检索。

**方案 B（更稳，适合真出海）**：**改名或加后缀**——如 "FactSlide" / "FactDecks" / "SourcePPT"，或干脆用中文品牌（如"事实说"/"溯源演示"）做国内主品牌 + FactPPT 做英文域名。加后缀可显著拉开与 FACTIFY 的近似度。

**方案 C（对冲）**：注册 FactPPT 时**同步注册决定性类目**（第 9、42 类：演示文稿生成软件、基于来源的内容验证 SaaS），抢在他人之前占位；同时把 "FactPPT" 与 "Fact Slide/Deck/Verity" 等防御性域名一并拿下（已验证全部可注册）。

### 5.3 立刻可做的事

| 动作 | 说明 |
|---|---|
| ✅ 注册 factppt.com（+ .cn 若做国内） | 今天就可做，价格低 |
| ✅ 顺手注册 factppt.net / factppt.io 防御 | 防抢注，成本小 |
| 📋 出海前做 US/EU/UK 商标冲突正式检索 | 重点是 FACTIFY 在第 9/42 类 |
| 📋 决定品牌名最终形态（FactPPT vs FactSlide 等） | 建议这周定，避免域名先绑死后改名 |

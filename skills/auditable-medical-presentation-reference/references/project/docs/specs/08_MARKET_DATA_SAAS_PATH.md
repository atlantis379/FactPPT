## 2. 关键口径解读（必须理解，否则会误判市场）

### 2.1 AiPPT："公告 2000 万" vs "站长工具 37–78 万/月" 的巨大差异

| 口径 | 数值 | 说明 |
|---|---|---|
| 视觉中国公告（官方） | 单月访问量 **>2,000 万** | 全渠道口径（aippt.cn + aippt.com + 小程序 + SEO 落地页 + toB 页面等**合计**） |
| Hypestat：aippt.cn | 约 **38 万/月** | 仅主域名、仅 Web 桌面访问、不含移动端/小程序 |
| Hypestat：aippt.com | 约 **78 万/月** | 同上（国际域名） |

**解释**：AiPPT 的商业模式是"流量池"（嘉程报告原文）——通过大量内容页/落地页/工具矩阵把流量引到多个域名与小程序。官方 2000 万是**全渠道 UV 口径**；站长工具只能看到**单域名 Web 桌面**这一个切面。**两者都对，代表不同度量维度。**

|---|---|---|---|

## 3. 对商业化的三个新结论（加入流量数据后）

### 3.1 你的"忠实转换"定位在国内市场有巨大的空白位

- 国内 AI PPT 头部（AiPPT/百度文库）都走"**快 + 好看 + 免费/低价**"路线，**没有任何一家把"数字精确/来源可追溯"作为卖点**（我们在 §竞品社区已验证 Gamma 用户都在喊，国内工具同理甚至更弱——中文数值处理更差）；
- 你不需要去抢 2000 万的"大众 PPT 流量"，你要的是其中**一小撮"材料敏感、需要精确"的专业用户**（医生/律师/研究员/教师）——这部分用户当前在 AiPPT/百度文库上**得不到满足**，是空白。

### 3.2 SaaS 的必要性被流量数据再次加强

- 国外 Gamma 3000 万月访问、国内 AiPPT 2000 万——**都是网页/SaaS 形态才可能有的量级**；
- 你的差异化（审计报告/逐值溯源）作为**网页端交付物**，比桌面文件更适合传播与在线协作；
- 结论不变且更强：**最终形态是 SaaS**，但入口用"内容营销 + 专业社区"而非烧钱投流（你的多平台对照审计内容本身就是获客武器）。

### 3.3 定价锚的新校准（加入量级参照）

| 参照 | 月访问量级 | 对定价的启示 |
|---|---|---|
| Gamma 3000 万/月 | 靠 $8–16/月 海量用户 | 个人版低价走量可行（¥9.9–99） |
| Beautiful.ai/Tome 100–200 万/月 | 靠专业订阅 | 中端专业版（¥200–600）空间存在 |
| AiPPT 2000 万（全渠道） | 免费+增值 | 免费试用引流 → 审计报告付费——你的防白嫖策略更可行（国内用户习惯免费起） |

## 4. 数据局限声明（必须公开）

1. **Hypestat/SEMrush/SimilarWeb 均为估算**，且相互之间有显著差异（如 gamma.app：HS 3160 万 vs SEMrush 2660 万；同一工具的"月访问"与"月唯一访客"也不同）；
2. **站长工具只测单一主域名的 Web 桌面流量**，不含移动 App/小程序/H5 落地页——对"流量池"型产品（AiPPT）严重低估；
3. islide.cc 数据未含其插件装机量（插件才是 iSlide 的主力，网页只是模板市场）；
4. wenku.baidu.com 是百度文库子域，其"127 亿"是站内部流量，**不可与独立站点横向比**，仅作参照；
5. 如需更高精度：① 订阅 QuestMobile/月狐完整报告（国内 App+小程序口径）；② 用 SimilarWeb API（付费）拿多域名合并口径；③ iSlide/AiPPT 的**移动端 App 数据**不在网页流量内。

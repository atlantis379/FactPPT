## 0. 定位与责任边界（产品定义，先于一切对标）

**产品**：一台"不撒谎的材料翻译机"——把用户提供的医学/专业材料（PDF、课件、文献）在**维持数据精确、逻辑一致、出处可查**的前提下，转换为可讲的演示文稿。

**责任边界（用户原始定义，与 PRD Source Fidelity 原则一致）**：
- ✅ **负责**：转换过程忠实地反映原始材料——不篡改数字、不编造逻辑、不引入来源外医学事实。
- ❌ **不负责**：材料本身的医学正确性、临床判断、渠道合规——那些是**使用者**的责任（系统在 W16 强制人工审查 RED 高风险页，正是把"内容判断权"交还使用者）。
- 对应工程实现：`Source Fidelity ≠ Clinical Correctness`（04_QUALITY_AND_COMPLIANCE.md）；128条冻结规则 + 校验脚本保证转换层精确，人工审查层保证判断权归属。

**一句话定位**：**在 AI 普遍幻觉的时代，给你一个"数字不改、逻辑不乱、句句可回溯"的转换器。**

## 5. 验证证据（2026-09 实机测试，本闭环的核心依据）

### 5.1 端到端运行：TEST005（口腔专业教学 · 90min）

- 原始材料：《呼吸衰竭与呼吸支持技术》（64页）+《肺部感染性疾病》（66页），两份真实教学课件；
- 产出：49 页可编辑教学稿 + 逐页渲染证据 + 审查单；
- **自动化全绿**（`RUN_STATE_TEST005.json` / `W18_BENCHMARK_RECORD_TEACHING.md`）：
  - W00–W14 全部 PASS（抽取→建证→组织→生成→审计）；
  - 精确文本 49/49（关键阈值逐字核对，数字突变 0）；
  - 官方检查器 49/49（字形 0 缺失、构图 PASS）；
  - 49 张渲染 PNG 哈希绑定，独立目视复核待完成；
- 剩余唯一未完成：**W16/W17 人工审查**——这是设计使然（RED 高风险页由教师核对），不是缺陷。

### 5.2 四路径对照与双向审计（`CROSS_PLATFORM_FIDELITY_AUDIT_v0.2.md`）

同一原始材料，四条生成路径：

| 版本 | 路径 | 页数 | 反向审计（来源外医学事实） | 正反判定 |
|---|---|---|---|---|
| **A1** | skill + DeepSeek | 49 | **0 幻觉**（42 数值 token 全部回溯；教学思考题已显式标注「整理思考」） | ✅✅ 双通过 |
| **A2** | skill + ChatGPT | 33 | **0 幻觉**（12 数值 token 全部回溯；差异仅为教学精简取舍） | ✅ 忠实，覆盖浅（合法） |
| **A3** | 图片版（A2 渲染） | 33 | 不可程序化核对（文本像素化） | ⚠ 结构保留，审计阻断 |
| **B** | Gemini Notebook 无约束 | 15 | 不可程序化核对；**目视发现原文没有的过度绝对表述**（"Ⅱ型必须低浓度吸氧"）+ 水印 | ❌ 视觉最好，医学风险最高 |

**关键证据结论**（支撑定位与差异化）：
1. **"忠实转换"是代码可验证的**：A1 的每个数字、单位、阈值都能回溯到原始材料（反向审计 0 幻觉），并可复现（脚本+工件齐备）；
2. **同一 skill、不同模型，覆盖深度不同但忠实度恒等**（A1/A2 均 0 幻觉，页数 49 vs 33 是教学取舍）——证明"流程可移植、精确性有保障"，而非"依赖某个特定模型"；
3. **图片化 = 可审计性归零**（A3）：文本进图片后逐字核对无法执行——这正是"可编辑层 + 哈希渲染证据"设计的价值；
4. **无约束生成 = 视觉最好、医学风险最高**（B）：出现原文没有的绝对化断言，不能用于教学——这就是本系统要解决的痛点。

## 6. 定价建议（三层模型，按"精确转换"锚）

定价逻辑（修正后）：锚点是三层价值——**①省工时（对比手工整理）②省心（不用逐字核数）③医疗语境下"改错一个数字"的代价**。不与通用 AI PPT 的"速度"锚竞争。

| 层级 | 形态 | 定价锚（建议区间） | 对标依据 |
|---|---|---|---|
| **① 个人版**（医生/学生单人） | 单次/月费 | **¥9.9–99/月** 或按项目付费 | 对标 iSlide/AiPPT ¥65–72/月，个人用得起 |
| **② 专业版**（科室/研究组/工作室） | 月费/席位 | **¥200–600/月/人** | 通用工具 3–8 倍，因为"精确+可回溯" |
| **③ 机构版**（医院/医药公司/内容服务商） | 年费 | **¥2万–20万/年** | 医学内容制作成本 + 医疗错误代价 |
| **④ 方法论/咨询**（现在可做） | 项目制 | **¥1万–10万/项目** | 标准共创、落地咨询 |

**支持证据**：A 组（skill 约束）已实证"精确性可验证"，所以第②层的"精确溢价"有据；同时 TEST005 已把第③层所需的核心能力（可追溯交付）跑通——**定价不再只是假设，而是有实测背书**。

## 一句话闭环结论

> **定位**：一台"只对原始材料负责"的忠实转换器——转换过程数字不改、逻辑不乱、出处可查；**证据**：TEST005 端到端全绿 + 四路径反向审计证明"来源外幻觉 = 0"（且可复现）；**竞品**：通用 AI PPT 用 ¥65–104/月锚定"快"，没有任何一家提供"可验证的准"；**定价**：个人 ¥9.9–99/月、专业 ¥200–600/月、机构 ¥2万–20万/年——溢价由"精确性证据"背书，而非口号。"快而不可信"与"可信而可证明"之间，就是本产品的商业空间。

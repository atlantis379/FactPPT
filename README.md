# FactPPTv2

独立的本地医学课件产品。主线为 **FactDeck**（`factdeck.v1`）：对各种类型的原始资料进行总结，
再按需求生成内容与原文一致、可编辑的 PPT。

**资料导入 → 逐页阅读与图表转录 → 全文总结 → 客户内容确认 → 事实库（逐字引文） → 按需求编排页面 →
独立语义审查与人工确认 → 程序渲染 → 前5页审核与风格确认 → 逐页审核 → PPT交付**

## 启动

需要 Windows、Python 3.12、Node.js 24.21.0。PowerPoint用于原有渲染复核功能。

```powershell
cd E:\FactPPTv2
.\install.ps1
.\start.ps1
```

默认服务 `http://127.0.0.1:8001`；也可双击 `start.cmd`。依赖已经按锁文件安装的机器可以直接启动。

新产品从空项目开始。旧项目数据未导入，原源码目录保留。新服务无需访问迁移来源目录。

## 能力

- 批量资料导入：PDF、PPTX、DOCX、XLSX、图片、TXT/MD，拆分为可精确定位的引用单元。
- 需求驱动：受众、目的、时长、目标页数、重点、语气；教学提纲全覆盖，未上页内容须说明原因。
- 事实库：页面上的实质内容全部是原文逐字节选，数字、单位、比较符号、专有名称由程序核对；
  来源冲突、非逐字推导、图表转录进入人工确认。
- 独立语义审查（不同执行端）与第二次独立转录。
- 程序渲染 9 种通用版式、5 套配色，自动适配字号；输出原生可编辑 PPTX、PDF、逐页 PNG，
  备注写入每条内容的来源位置。
- 两次本地客户确认、逐页审核，任何上游变化自动使下游失效；SQLite任务队列、租约、断点续作。
- 接口：主线 `/api/deck`；原整页图片流程 `/api/fact` 保留给已有项目；原语义流程在 `/legacy` 和 `/api/projects`。

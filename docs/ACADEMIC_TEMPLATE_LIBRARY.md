## 范围

每套六种样页：封面、章节、正文、对照、流程、表格，共60页。样例仅使用通用学术占位文字，不承载医学结论，不进入客户内容确认或正式页面审核。

## 制作与验收

完整带文字设计稿 → 实际查看与版面拆解 → 去字 → 查看去字稿 → Adobe矢量化 → 实际路径转原生PPT形状 → 原生占位文字、表格、连接线 → PowerPoint渲染与编辑检查。

每套保留提示词、实际工具输出及回执、差异记录。不能用整张背景、嵌入SVG或纯代码另画的简化版本冒充A路线完成品。

库内候选制作完成后展示真实预览。模板选择必须持久化，并进入后续设计合同；不能只替换配色却声称使用了整套模板。

3. 本科教学：暖白、墨绿。

5. 人文社科：米白、暗酒红。
6. 循证研究：白、灰青。
7. 工程技术：白、灰靛蓝。
8. 自然科学：砂白、灰橄榄。
9. 跨学科：白、低饱和紫。
10. 临床会议：白、钢蓝灰。

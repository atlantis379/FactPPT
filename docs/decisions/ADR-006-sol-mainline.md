# ADR-006 — GPT-5.6 Sol as Default Development Model

**Status:** ACCEPTED

## Decision
Use GPT-5.6 Sol as the default Lead Architect, Main Developer, and Independent Audit model. Expensive frontier models are not required for routine development.

## Controls
Quality is enforced by Frozen Contracts, Milestones, Rule Registry, tests, Golden Set, CI, Human Review, and separate-context Audit Passes.

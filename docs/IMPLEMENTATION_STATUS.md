# 实施状态

## 主线切换为 FactDeck（2026-09-27）

用户决定以 FactDeck（事实库 + HTML 渲染）替代整页 ImageGen 作为主线，并要求它是
面向各种原始资料、按需求生成 PPT 的通用生成线，而不是针对某一份资料。

### 已完成

- 引擎通用化（`factdeck/`）：
  - 去掉写死的药名表、机制图坐标和样例专用版式；关键项识别改为通用规则
    （数字+比较符号+单位、技术缩写、中文数量词）加项目术语，默认词表在 `config/factdeck_lexicon.json`。
  - 资料拆分支持 PDF、PPTX、DOCX、XLSX、TXT/MD、图片，区分“阅读页”和“可引用单元”。
  - 事实核对新增：显示文字必须是引文的逐字节选；删去否定/限定词视为改写；推导可被否定；冲突裁定后未采用的事实被拒绝。
  - 页面规格核对新增：版式结构与容量、提纲覆盖、总结章节覆盖或省略原因、页数与需求偏差提醒。
  - 10 种通用版式（原件图、封面、章节页、要点、表格、指标卡、对比、流程/机制图、核心结论、小结），5 套配色，逐页自动收紧字号。
- 应用流程（`app/deckflow.py`、`/api/deck`）：阅读与图表转录、总结、内容确认、事实库、页面规格、
  第二次独立转录、独立语义审查、人工确认（推导/冲突/转录/驳回问题）、正式与草稿渲染、
  前5页审核与风格确认、逐页审核、交付包；各环节按校验值绑定，上游变化自动使下游失效。
- 界面（`web/deck/`，Tabler MIT，版本与校验值见 `web/vendor/tabler/VERSIONS.txt`）：首页为项目列表与新建；项目页含
  阶段进度、需求与提纲、资料导入/移除、执行端任务排队、总结与客户内容确认、事实库、页面规格核对与覆盖、
  人工确认（冲突裁定、推导确认/否定、转录核对）与语义问题驳回、正式/草稿渲染、逐页审核、样页风格确认、交付包与审计记录。
  所有门槛仍由服务端判定；已用测试夹具项目在浏览器中从“待人工确认”点击走到“已交付”。
- 原件图片引用第一期（2026-09-28，`docs/FIGURE_REFERENCE.md`）：程序从 PDF/PPTX/DOCX/图片中取出内嵌图片（像素不变，
  过小的图标不登记）；阅读时逐张说明并转录图中文字；图事实与 `figure` 版式；每张上页图逐张登记截取与去标识确认
  （含可识别信息的图被拒绝）和客户使用许可；PPTX 插入存档原图并回读校验值与比例；低于 150 dpi 只提示；
  交付报告列出每张图的来源与确认记录。测试 `tests/test_figures.py`；浏览器中已用测试图点完确认与渲染。
  顺带修复：导入含图片的 PPTX 会因 `MSO_SHAPE_TYPE.GRAPHIC_FRAME` 不存在而报错。
- 执行端传输工具 `tools/codex_worker.py` 默认连接主线，支持全部新任务类型与渲染。
- 依赖：Jinja2、Playwright（Chromium）、pdfplumber 已加入锁文件与安装脚本。
- 测试：`tests/test_factdeck.py`（事实核对与作者文字）、`tests/test_deckflow.py`（四种格式资料走完整条主线到交付、
  独立性、失效链、草稿不可审核、接口挂载、首页界面及静态资源）。

### 验收边界

- 自动测试中的模型结果、确认和审核都是手写夹具与测试记录，资料是虚构内容；不是真实模型输出、客户签字或医学审核。
- 早期原型样例 `factdeck/examples/biologics` 已转换为通用版式，但本机缺少其 9 份原始资料中的 5 份，
  未在本机通过事实核对；只做了版式渲染检查。
- 尚未用真实资料和真实执行端完整跑一个项目。

### 尚未完成

- 总结章节的关键依据（2026-09-28 用户确认加入）：目前章节只引用到资料页，客户确认时难以核对某句归纳依据哪段原文。
  改为每章另列若干条 `key_points`（一句归纳 + 支撑它的文字单元编号），程序检查单元存在且属于本章引用的页，
  内容确认稿逐条附上原文。归纳本身仍由人确认，程序只保证“依据可查”。
- 原件图片引用第二期：PDF 区域截取（矢量图表）与 `compare` 面板放图（`docs/FIGURE_REFERENCE.md`）。
- 15 个旧测试因迁移时缺少样例文件/模块而失败（`app/validation/...`、`assets/editorial/...`、
  `tests/fixtures/source_intake/`、`app.validation.semantic_act_qualification`），与主线无关，待补齐。

### 不计划做

- 插画生成（2026-09-28 决定）：页面由代码渲染后，版式、装饰和图示都已由代码绘制，插画只能增加观感。
  而医学课件里有价值的写实插画（机制、解剖）本身在表达内容，无法对应到逐字引文，也过不了程序核对。
  需要图时改用原件图片引用。

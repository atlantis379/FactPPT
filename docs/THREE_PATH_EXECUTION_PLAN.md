日期：2026-10-04。状态：用户已决定采用此分工；FactDeck自动模型路由尚未实现。

## 本次试跑模型覆盖（2026-10-09）

用户指定当前章节试跑中所有需要模型判断的工作统一使用 **6 Luna**。本次 DECK 页面编排由 Luna 生成；FACTS 的逐字截取、引用与覆盖检查仍由本地代码完成，不为此重复调用模型。并行分组使用不同执行身份；后续独立审核也使用 Luna，但必须由未参与该版本编写的独立执行身份完成。此覆盖仅适用于本次试跑，不代表生产环境已经具备自动模型路由，也不改变人工确认与页面审核关口。

## 决定与范围

用户决定放弃本地模型。当前内容处理和任务协调只考虑三个路径：**6.1 Sol、6 Luna、本地代码**。停止本地模型接入、资格测试和后续推理实验；已有实验、工具及失败记录保留为历史证据，生产流程不调用它们。

内容确认、来源冲突裁定、风格确认和逐页人工审核继续作为原有关口。A原生矢量路线使用的ImageGen、Adobe及PowerPoint继续按现有真实工具合同执行；它们是工具依赖，不能算成Sol/Luna推理或本地代码生图。这项决定不替换视觉工具。

## 分工原则

- 本地代码先完成可确定的工作，给模型实际证据、目标与合同，不反复传完整项目状态。
- Luna负责目标明确的局部候选。涉及跨页续句、复杂条件、表格关系、箭头或来源冲突时，任务交Sol。
- Sol负责整章综合、教学组织、关系判断、设计决策及独立内容审核。分工是当前执行策略，不代表已取得免审核资格。
- 作者与审核者必须是不同执行身份；SUMMARY_REVIEW同时避开CLAIMS作者，SEMANTIC_REVIEW避开事实库和页面作者，SECOND_READ避开首读者。使用同一模型名不自动证明独立性，换模型名也不能替代输入隔离和身份检查。
- 代码检验引用、数字、结构、版本和覆盖，不裁定语义正确或审美通过；所有确认依原应用关口。

## 升级和返工规则

1. 非模型问题（格式包装、固定元数据、网络重传、失效租约、缺文件）先由代码定位和恢复。原响应、错误及实际调用记录保留；不改医学文字，不补造证据。
2. Luna的局部候选遇到复杂条件/跨页依赖/语义阻断时，把失败目标、审核意见、实际原文与必要邻页交Sol。已经成功的页面不重新生成。
3. Sol修订过的内容仍要由符合独立性要求的执行端复核。未解决BLOCKER、待确认转录或来源冲突继续停在原关口。
4. 局部拆分不能跳过原文页；整章Sol综合和独立遗漏检查必须覆盖全部来源及提纲。减少单包大小不等于减少全部token。
5. 并行任务复用SQLite领取和独立租约。Office导出串行，视觉工具并发按实际额度执行。模型角色按任务记录，不能靠同一作者改worker名称取得独立审查资格。

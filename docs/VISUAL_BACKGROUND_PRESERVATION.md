# 设计参考的背景保留与原生重建

适用于A路线的任何主题、页型和风格。按元素的作用、来源与视觉影响决策，不按物体名称设白名单。生成参考图不提供事实权威。

## 分层与判断

| 层 | 判断依据 | 处理 |
|---|---|---|
| 背景与装饰 | 作用是建立环境、风格、层次、空间边界或视觉重心，不表达需要来源支持的事实 | 保留整体构图及主要色面，分别转成可编辑原生对象 |
| 信息图形 | 通过标签、数量、比例、坐标、类别、方向、包含/排除或结构隐喻传递实质含义 | 按锁定来源核对；无依据的含义局部删除或修订，其他装饰不连带删除 |
| 内容对象 | 来源绑定的文字、数字、表格单元格与关系 | 移除生成版本，精确填入锁定原生对象 |
| 混合作用元素 | 同时具有装饰和信息意义 | 拆成可独立判断的组件；不能笼统按背景保留或整体删除 |

不得仅因元素出现在背景区域就认定它无信息意义，也不得因出现学科相关物体就认定它有不受支持的事实含义。判断须写明它表达了什么、是否与来源冲突、是否影响阅读。

## 去字与清理

先标出内容位置及混合作用组件，只移除需要替换的文字、数值、关系或错误含义。保持原有背景的主要色面、轮廓、分区、相对比例与位置。去字后的空白必须与设计意图相符；不得因清除内容而丢失承担视觉重心的非信息图形。

背景干扰正文时优先调整局部位置、对比度或留白；更换构图应记录为设计变更，不能称为忠实重建。若信息与装饰无法可靠分离，列为待处理并说明，不由模型猜测补全。

删除错误信息图形不等于完成该区域。若该图形承担解释或阅读导航作用，必须有来源允许的替代表达，或明确列为待处理；保留空图标底座不能记作完整交付。判定曲线时须区分无标定的概念图标与实际数据图，但概念图标也须与被解释内容相符，不能仅加“示意”便豁免错误图义。

## 矢量化与损失

实际PNG → 实际Adobe SVG → 原生路径。SVG仅作中间资产，不能嵌图冒充可编辑几何。按组件分组，保留相对位置和叠放关系。

允许纹理、细小笔触和渐变出现约定范围内的损失；须比较原图与实际PowerPoint。分开记录：去字导致的改变、Adobe描摹损失、SVG转原生损失、文字填充导致的遮挡。复杂度由边缘/细节密度、透明/渐变/纹理、叠放关系及混合语义决定，不由具体物体名称决定。

## 交付复核

每页保存带定位的元素清单：区域、作用、来源/冲突证据、保留或修订决定、损失说明。比较完整设计、清图和实际原生输出：

1. 视觉主体、背景主要分区与重心是否保留；删除或移动是否有具体原因。
2. 信息含义是否由锁定来源支持，不能以美观为理由保留错误关系。
3. 原生对象是否可分别编辑，文字是否遮挡主体；各层是否能单独调整。
4. 客户是否接受实际输出及明确列出的差异。几何校验或路径数量不替代客户审美判断。

范例只用于验证规则，不构成某类物体必须保留的固定清单。

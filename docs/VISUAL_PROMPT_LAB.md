## 验收顺序

1. **准确性硬门槛**：没有新增医学含义、虚构数据/统计区间、条件或否定丢失、比较方向错误、实质内容重复。完整源文字由代码锁定；生成图不是来源依据。
2. **解释能力**：节点有来自原文的标签，图形能读出分类、差异或条件，不是大文字框配装饰。适用范围与被限定的节点同区；表格/流程及分支不可因美术而改义。
3. **审美**：内容标题优先、并列等权、密度适合本科教学、装饰克制、整体一致。实际候选由用户选择；自动指标不能代替审美。
4. **交付能力**：图形真正原生可编辑，纹理损失记录；原生文本/表格/单位/来源逐项回读，PowerPoint实际画面无溢出、遮挡。

同类硬错误反复发生时调整图解结构/约束，不通过反复抽图挑一个侥幸成功的结果。未通过候选不得凭审美分数进入交付。临时评选不记录医疗批准或客户风格确认。

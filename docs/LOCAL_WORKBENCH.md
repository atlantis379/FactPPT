# 本机PPT工作台

日期：2026-10-04。入口：`http://127.0.0.1:8001/`。使用现有Tabler MIT前端和FactDeck API；无本地模型。

## 使用

运行根目录`start.cmd`（默认端口8001），浏览器打开本机入口。填写右上角操作人姓名，创建项目并依次使用五步导航：

1. **上传资料**：支持已有PDF/Office/文本/图片导入，多文件逐个存档，显示上传中的文件位置和资料读取状态。
2. **要求与模板**：受众、时长、页数、提纲、重点及其他要求；五种现有配色风格可预览并保存，也可上传自己的PPT模板及Logo。模板读取字体/配色，不继承完整母版或版式。
3. **内容复核**：原始页图与总结并排查看，从要点跳转实际原页；可查看转录、独立审核和未决问题。可在页面修改总述、章节摘要、已有要点文字及待处理事项，保留既有来源引用。保存后自动排队独立审核，旧确认失效；增加新来源/要点应通过执行端重做候选。
4. **生成与审核**：确认已完成的内容进入A原生矢量流程，查看逐页资产/任务进度，先审核样页与确认风格，再逐页审核内容/视觉。未满足前置条件时正式生成按钮禁用；后端仍是验收权威。
5. **下载交付**：全部正式审核和确认通过后生成交付包，下载原生PPTX、PDF、逐页图片和来源/验证报告。部分页面完成不作为整套可交付。

每一步上方显示当前待办和实际可执行操作，复杂内容明细在“执行记录与内容明细”展开。任务领取过期会单独显示，不能误计为仍在处理。

## 实际执行边界

按钮调用真实队列、确认、生成和交付接口；语义/视觉任务仍由现有Codex＋Adobe执行端领取和提交。Sol/Luna按`THREE_PATH_EXECUTION_PLAN.md`分工。服务器尚不能无人值守调用这两个模型或视觉工具，不将“已排队”显示为模型已运行。

采用本地记录身份，尚无账号认证/多租户隔离。本版没有新建在线SaaS、改写业务确认、自动签署审核或执行本地模型。已有项目和历史API继续使用原数据/SQLite事务。

## 进度与输入保护

- 新增只读`GET /api/deck/workflows/{id}/progress`，仅返回项目ID、阶段、更新时间及任务ID/状态/尝试数，轮询不传完整原文、总结和资产。
- 待处理任务每10秒查看进度，变化时刷新当前页面。正在输入或已有未保存修改时保留页面并提示刷新。
- 未保存修改离开/关闭页面会提示。保存失败保留编辑；总结保存成功但审核排队失败时明确报告两步状态，允许再排队。
- 内容修订继续通过现有SUMMARY验收器；独立性、版本、所有要点覆盖、人工确认与交付关口保持原规则。

## 页面指引（2026-10-04）

首页显示入门顺序及每个项目的下一步和继续处理入口。项目页面显示当前版本的四阶段状态、操作责任和具体说明；待领取任务明确提示需要Codex执行端，不表示模型已运行。入门说明可展开查看，确认与审核关口不变。


页面责任说明：首页区分需要用户操作与执行端处理；项目上方显示用户、执行端、系统三方职责。内容修订及独立审核归执行端，人工确认与逐页审核归用户。相关卡片带操作／查看标记；系统自动阶段不显示为人工确认。


2026-10-08：恢复本机服务与中断审核。总结独立审核待完成、存在阻断及待内容确认三个阶段均可在待确认与问题查看来源待确认清单；审核通过且待确认清单为空时才显示内容确认表单。未更改后端确认关口。

确认页改为三步操作：逐项保存版本绑定的人工答复，执行端根据答复处理并独立复核，最后填写确认人并提交本版本确认。审核明细和高级总结编辑默认收起；答复记录不清空pending_issues、不产生内容确认、不改变审核输入。新增接口POST summary/pending-responses使用SQLite事务及独立快照保存，拒绝过期版本、不完整答复和无依据的AVAILABLE选项。工作台接口回归3项通过。

人工答复自动推进：保存答复后事务内排队SUMMARY_AMEND，页面进入答复处理中；局部修订合同仅允许改总述、章节来源限制及已明确答复的待确认事项，锁定要点/引用/覆盖，UNKNOWN事项必须保留。同版本重复答复去重。完成局部修订自动排队SUMMARY_REVIEW，最终内容确认仍由用户提交。自动队列已接入现有Codex执行端；无人值守模型启动尚未实现。

## 学术模板选择（2026-10-11）

项目“要求与模板”提供10套已经核对的学术原生样例，可按教学课件、论文答辩、临床汇报、学术研讨筛选。卡片显示适用内容、视觉气质、配色、实际六页预览与可编辑下载。当前选择置顶，选择后标记“已选择”；不会替用户自动选择。

制作开始后更换模板，页面明确提示已有视觉稿及相关视觉确认需重做，原已确认内容保留。A路线按样例重建，并不直接继承POTX母版。

独立模板页：`#/w/{项目编号}/templates`。在“要求与模板”步骤切换“生成要求／选择模板”；生成要求页显示当前选择与明确入口，模板页提供预览、筛选、选择及返回当前处理步骤。公共 `#/templates` 继续用于浏览下载。

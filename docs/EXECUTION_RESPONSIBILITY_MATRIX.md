## 口径

- **云端模型**：当前Codex执行端负责的阅读、理解、选择、总结、审查和设计判断。应用管理任务和验收，不直接代替执行端调用全部这些模型。人工也可按合同完成相应任务。
- **本地代码**：项目应用、Python/浏览器程序、原生PPT导出和本机PowerPoint负责的确定性执行。模型发起程序操作时，操作本身仍属于代码；用agent反复调度会额外产生模型上下文。
- **外部视觉工具**：ImageGen、Adobe实际生图、编辑及矢量化能力，单独记调用和费用；不将其标为本地代码。
- **本地模型**：现有Bonsai27B已完成小样本实验，但候选worker尚未接入生产。下文“拟迁移”均是改造目标。
- **人工**：内容确认、冲突裁定、风格偏好及最终审核，由相应审核人负责。

## 六、优先改造顺序

1. **先用代码减少重复执行和输入**：补逐项审核槽；正文去重；短回执；来源/任务缓存；续约和恢复；JSON包装及原文定位。
2. **接入本地候选worker**：先图表转录、事实跨度选择，再分别评估CLAIMS类型和分章草稿。
3. **保留云端独立理解与审查**：输入使用实际需要的证据，遇到歧义补邻域/原页；不把本地候选结论当正式通过。
4. **保留外部视觉工具及人工关口**：A路线质量与原生可编辑交付按原流程验证。

无损原型测得SUMMARY输入包字节减少27.42%，审核输入包减少21.39%；未测实际云端token或费用节省。拆成8章时总输入字节反而增加3.43%，因此按全部调用合计评估效果。

## 八、本轮云端分工与实测结论

同一S03章节两份云端候选经过同一独立执行端逐项复核及一轮修订。Sol剩0阻断、26待处理；Luna剩4阻断、2待处理。本机Bonsai剩4阻断、53待处理。三组均未到可确认终点，实际费用和云端计费token不可观察。报告见`output/chapter_draft_benchmark/comparison.md`。

| 工作 | 暂定分工 | 边界 |
|---|---|---|
| 请求/来源清单、重复正文、短回执、资产复用、格式/真实编号验收 | 本地代码 | 确定性工作先移出模型输出；提供证据不等于模型已正确理解 |
| 条件密集总结、跨页语义综合、独立忠实度复核 | 6.1 Sol优先 | 仅为本项目暂定执行分工，保留独立身份和人工确认；本章不是全任务资格测试 |
| 章节首稿候选 | 6 Luna可试用 | 必须计入完整独立审核与返工，本轮一轮修订仍有阻断 |
| 局部原文跨度/摘录候选 | Bonsai另测 | 程序从原文取回并验证；不得据本轮SUMMARY实验替代正式审核 |
